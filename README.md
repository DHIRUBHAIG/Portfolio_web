# Dhiraj Kumar Gupta Portfolio

Modern recruiter-focused portfolio website built with Next.js, Tailwind CSS, and Framer Motion.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create `.env.local` from `.env.example` and add your EmailJS credentials.

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Features

- Glassmorphism UI
- Dark theme with theme switcher
- Responsive one-page layout
- Advanced portfolio sections
- Animated scroll progress
- Contact form with EmailJS integration
- SEO metadata and Open Graph tags
- Resume download support
